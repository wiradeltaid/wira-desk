### Architectural Invariants & Key Subsystems (Compacted Reference)
- **Privilege & UIPI**: Daemon runs elevated (`requireAdministrator`) to inject synthetic inputs across elevated windows (Task Manager, elevated terminals). Settings GUI runs unelevated and binds to daemon lifetime via named pipes/IPC.
- **Hook Thread Decoupling**: Low-level keyboard (`WH_KEYBOARD_LL`) and mouse (`WH_MOUSE_LL`) hooks execute within 1-2 CPU instructions, forwarding mouse moves instantly to prevent cursor micro-stutter. Action events are pushed into lock-free ring buffers drained by worker threads, immunizing hooks from OS `LowLevelHooksTimeout` watchdog death.
- **Driverless Mouse Navigation**: Captures standard USB HID auxiliary messages (`WM_XBUTTONDOWN`, `WM_MOUSEHWHEEL`). Tilt wheel burst packets are debounced at 150-200 ms. Actions dispatch to 20 configurable presets across 8 categories (virtual desktop switching, task view, media, snapping). Virtual desktop switching uses stable `SendInput` keyboard chords (`Ctrl+Win+Left/Right`) rather than fragile undocumented COM interfaces (`IVirtualDesktopManagerInternal`).
- **Same-App Window Cycling & Visual Switcher**: `Win + \`` cycles windows sharing the same process executable name. Visual thumbnail overlay triggers on hold past 300 ms (`visual_hold_delay_ms`). Tap cycling traverses windows on the active monitor; hold cycling displays windows across all physical monitors on the active virtual desktop. Unwanted helper windows (`PopupHost`, invisible tooltips) are sanitized before candidate evaluation.
- **Window Snapping Engine**: Supports halves, thirds, and custom-percentage edge snapping (default 67%). Layout engine applies DPI-aware border compensation and clamps bounds to monitor work areas.
- **Settings UI & Slint Runtime**: Built with Slint native UI framework using software renderer backend and static CRT linking (`+crt-static`). Compiles with zero runtime C-runtime DLL or GPU driver dependencies, yielding a single ~6.8 MB self-contained binary. Configuration persists to `%APPDATA%\WiraDesk\config.toml`.
