## Установка

### Через Scoop (Рекомендуется)

```powershell
scoop bucket add wiradesk https://github.com/wiradeltaid/scoop-wiradesk
scoop install wiradesk
```

### Установочный пакет (Setup Executable)

Загрузите программу установки (`WiraDesk-*-x64-setup.exe`) со [страницы релизов](https://github.com/wiradeltaid/wira-desk/releases) (зеркало на [SourceForge](https://sourceforge.net/projects/wira-desk/files/latest/download)) и проверьте хэш SHA-256:

```powershell
Get-FileHash .\WiraDesk-*-x64-setup.exe -Algorithm SHA256
```

Устанавливается с повышением прав в `%ProgramFiles%\Wira Desk`. Автозапуск при старте системы опционален и настраивается в параметрах или через значок в системном трее.

### Портативные бинарные файлы (Portable)

Загрузите отдельные бинарные файлы `wiradesk.exe` и `wiradesk-settings.exe` в директорию с правами администратора и запустите `wiradesk.exe` от имени администратора.

## Основные возможности

- **Переключение окон одного приложения (Same-App Window Cycling):** Сочетание ``Win + ` `` циклически переключает окна только активного приложения на текущем мониторе и виртуальном рабочем столе (резервная комбинация: ``Alt + ` ``). Быстрое нажатие переключает мгновенно, а удержание 300 мс открывает визуальный переключатель с живыми миниатюрами.
- **Зонирование окон в одно касание (One-Key Zone Snapping):** Мгновенная привязка окон к половинам экрана (50%), третям (33%) или настраиваемым пропорциям (по умолчанию 67%, сверху 33%) без открытия громоздких редакторов зон.
- **Навигация мышью без сторонних драйверов:** Переназначайте боковые кнопки мыши (`XBUTTON1`/`XBUTTON2`) и наклон колесика на переключение виртуальных рабочих столов или 20 готовых пресетов без вендорных утилит.

### Сочетания клавиш по умолчанию

| Сочетание клавиш | Действие |
|---|---|
| ``Win + ` `` | Переключение окон активного приложения (удержание 300 мс — визуальный оверлей) |
| ``Alt + ` `` | Резервное сочетание клавиш для переключения |
| `Ctrl+Alt+Left/Right/Up/Down` | Привязать активное окно к соответствующей половине (50%) |
| `Ctrl+Alt+Shift+Left/Right/Up/Down` | Привязать окно к краю с настраиваемой долей (67% по умолчанию, сверху 33%) |
| `Ctrl+Alt+1/2/3` | Привязать окно к левой, центральной или правой трети экрана |
| `Ctrl+Alt+Enter` | Развернуть окно на весь экран |
| `Ctrl+Alt+Shift+Enter` | Переместить окно на следующий монитор |
| `Ctrl+Alt+Shift+S` | Выстроить 3 окна в ряд с настраиваемой шириной |

### Пресеты для кнопок мыши

Боковые кнопки под большой палец по умолчанию переключают на предыдущий/следующий виртуальный рабочий стол; наклон колесика вызывает «Показать рабочий стол» / «Представление задач». Каждое действие можно переназначить в настройках на один из 20 пресетов. Координаты курсора никогда не считываются (см. [`PRIVACY.md`](PRIVACY.md)).

## Почему именно Wira Desk

В то время как PowerToys содержит Window Hopper, а фирменные утилиты производителей настраивают кнопки мыши, они потребляют 150–500 МБ оперативной памяти в нескольких процессах. Wira Desk работает как единый легковесный нативный фоновый процесс, потребляя всего около 4.0 МБ памяти (с запасом укладываясь в лимит 5 МБ), и не содержит телеметрии.

## Конфигурация и разработка

- **Конфигурация:** Файл настроек хранится по пути `%APPDATA%\WiraDesk\config.toml`. Полное описание формата TOML см. в [docs/CONFIGURATION.md](docs/CONFIGURATION.md).
- **Разработка:** Проект создан на Rust и MSVC. Руководство по сборке, тестированию и написанию unsafe-кода доступно в [DEVELOPMENT.md](DEVELOPMENT.md).
- **Участие в проекте:** Мы приветствуем вклад в разработку открытого исходного кода — см. [CONTRIBUTING.md](CONTRIBUTING.md).
