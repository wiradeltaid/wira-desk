# Planning Archive & Run Workspace

This directory is the designated run workspace for BMAD / WDI Method skills (`_bmad-output/`).

Per WDI Method Article 3, this directory is committed to git as the uncurated workspace for skill runs. 

Historical sprint artifacts, planning documents, and early specifications from the initial prototyping phase (WinTick 2026-07) have been pruned as the active, authoritative specifications live in:
- Product requirements: `.what/`
- Technical architecture: `.how/`
- Active specifications & tickets: `.scratch/`
- Archived specifications: `.archive/`
- Preserved technical research: `docs/research/mouse-navigation/`
