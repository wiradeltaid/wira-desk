## Progress

### 2026-09-18 — Research Preservation & Rendered Trees Untracking
- **Technical Research Documentation**: Preserved foundational technical research on driverless mouse navigation in `docs/research/mouse-navigation/`, documenting USB HID reports, low-level Win32 hooks (`WH_MOUSE_LL`), tilt wheel debouncing, and OS virtual desktop dispatch.
- **Rendered Markdown Hygiene**: Aligned repository with WDI ecosystem standard where `.what-rendered/` and `.how-rendered/` are untracked derived projections regenerable via `uv run validate.py --generate`.

### 2026-09-16 to 2026-09-17 — Preset 1 Alignment & Technical Guide Delegation
- **README Preset 1 Alignment**: Condensed `README.md` below 90 lines following WDI Preset 1 (Minimalist Utility / OpenLogi benchmark). Added language bar (`docs/README.*.md`), placed Scoop 1-click install upfront, highlighted the honest conditional "uninstall both" headline, and added the PowerToys 0.101+ Window Hopper comparison.
- **Delegated Guides**: Separated technical depth into dedicated guides:
  - `DEVELOPMENT.md`: Prerequisites, MSVC static CRT compilation (`+crt-static`), manifest bypass testing (`$env:WIRADESK_SKIP_MANIFEST = '1'`), and Win32 FFI `SAFETY:` comment requirements.
  - `docs/CONFIGURATION.md`: Full reference for `%APPDATA%\WiraDesk\config.toml`, documenting all configuration tables, defaults, and 20 mouse action presets.
- **GitHub Templates**: Created standardized issue templates (`bug_report.md`, `feature_request.md`) and pull request template (`pull_request_template.md`).

### 2026-09-16 — Public Facts Registry & Publication Hygiene
- **Canonical Facts SSOT**: Created `docs/public-facts.yaml` holding single authoritative values for version, RAM budgets, installer metrics, URLs, and delay constants. Verified continuously via `scripts/verify-public-facts.ps1` in CI.
- **Privacy & Retention**: Corrected `PRIVACY.md` to reflect actual ~2 MB log rotation with one `.old` generation.
- **Anti-Drift Rule**: Enforced in `CONTRIBUTING.md` that front-page README mirrors in `docs/` (`README.zh-CN.md`, `README.ja.md`, `README.id.md`) must be updated in the same commit whenever `README.md` changes. Reference and technical documents remain English-only.
